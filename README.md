# Calculadora JavaFX

Calculadora simples feita em JavaFX com tema personalizável via ColorPicker.

## Funcionalidades

- Operações: `+`, `-`, `×`, `÷`
- Alteração de cor em tempo real através do ColorPicker
- Botão `C` para limpar

## Tecnologias

- Java 17+
- JavaFX 21
- NetBeans (Java with Ant)

## Estrutura

- `src/calculadora/Calculadora.java` — classe principal
- `src/calculadora/CalculadoraControlo.java` — controlador
- `src/calculadora/calculadora.fxml` — interface
