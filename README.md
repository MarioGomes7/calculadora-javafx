# Calculadora JavaFX

Calculadora simples feita em JavaFX com tema personalizável via ColorPicker.

## Funcionalidades
- Operações: `+`, `-`, `×`, `÷`
- Alteração de cor em tempo real
- Botão `C` para limpar

## Tecnologias
- Java 17+
- JavaFX 21
- NetBeans (Java with Ant)
